# SeatUP

React Native / Expo приложение для Android по предоставленному макету. Русский интерфейс, каталог и поиск ресторанов, фильтр кухни, избранное, карточки заведений, выбор даты, времени и числа гостей, подтверждение и отмена брони, редактирование профиля. Брони, избранное и профиль сохраняются через AsyncStorage.

## Запуск

Требуется Node.js 22.13+ и npm.

```sh
npm ci
npm start
```

Откройте проект в совместимой с Expo SDK 58 версии Expo Go на Android. Для эмулятора с установленным Android SDK: `npm run android`.

```sh
npm run typecheck
npx expo export --platform android
```

## Android APK

```sh
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

Для облачной сборки нужен аккаунт Expo и привязка проекта EAS. Готовый APK в репозитории отсутствует. Профиль production предназначен для сборки AAB для Google Play.

## Границы демонстрации

Рестораны и отзыв — демонстрационные данные. Фотографии загружаются с Unsplash и требуют сети. Брони сохраняются только локально и не отправляются ресторанам. SMS, сервер, реальные платежи и карта пока не подключены. Номера банковских карт приложение не запрашивает. Для настоящего сервиса потребуется отдельный backend и интеграции.

## Ручная проверка

1. Найдите Pasta House поиском, примените фильтр кухни и добавьте ресторан в избранное.
2. Откройте ресторан, выберите дату, время, гостей и подтвердите бронь.
3. Проверьте бронь во вкладке «Брони», перезапустите приложение и убедитесь, что данные сохранились.
4. Отмените бронь и проверьте статус. Измените имя в профиле.
