# SeatUP

React Native / Expo приложение для Android по предоставленному макету. Русский интерфейс, каталог и поиск ресторанов, фильтр кухни, избранное, карточки заведений, выбор даты, времени и числа гостей, подтверждение и отмена брони, редактирование профиля. Брони, избранное и профиль сохраняются через AsyncStorage.

## Запуск

Требуется Node.js 22.13+ и npm.

```sh
npm ci
npm start
```

Откройте проект в совместимой с Expo SDK 58 версии Expo Go на Android. Для эмулятора с установленным Android SDK: `npm run android`.

```sh
npm run typecheck
npx expo export --platform android
```

## Android APK

```sh
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

Для облачной сборки нужен аккаунт Expo и привязка проекта EAS. Готовый APK в репозитории отсутствует. Профиль production предназначен для сборки AAB для Google Play.

## Границы демонстрации

Рестораны и отзыв — демонстрационные данные. Фотографии загружаются с Unsplash и требуют сети. Брони сохраняются только локально и не отправляются ресторанам. SMS, сервер, реальные платежи и карта пока не подключены. Номера банковских карт приложение не запрашивает. Для настоящего сервиса потребуется отдельный backend и интеграции.

## Ручная проверка

1. Найдите Pasta House поиском, примените фильтр кухни и добавьте ресторан в избранное.
2. Откройте ресторан, выберите дату, время, гостей и подтвердите бронь.
3. Проверьте бронь во вкладке «Брони», перезапустите приложение и убедитесь, что данные сохранились.
4. Отмените бронь и проверьте статус. Измените имя в профиле.

## Карта ресторанов

Вкладка «Карта» использует `react-native-maps`: масштабирование и перемещение, метки заведений, поиск, фильтр кухни, сортировка относительно центра карты, разворачиваемая панель списка, переход к ресторану и бронированию. Кнопка «Показать на карте» центрирует выбранную метку. Избранное остаётся отдельной вкладкой.

Координаты демонстрационные и не подтверждают расположение реальных заведений. Геолокация устройства не запрашивается; «Рядом с центром карты» сортирует по центру видимой области. Доступность столиков и часы работы сервером не проверяются.

Для собственной Android сборки включите **Maps SDK for Android** в Google Cloud, настройте биллинг и задайте `GOOGLE_MAPS_API_KEY` в окружении сборки EAS (не в Git). `app.config.js` передаст ключ плагину react-native-maps. Ограничьте ключ пакетом `com.seatup.app` и SHA-1 сертификата подписи. После настройки пересоберите APK: ключ встраивается при нативной сборке. Без ключа подложка Google Maps в отдельном APK работать не будет. В совместимой Expo Go используется конфигурация карт Expo Go.

Проверка на устройстве: откройте «Карта», переместите и увеличьте карту, выберите метку, измените поиск/кухню и проверьте синхронное изменение списка и меток. Разверните и сверните список, нажмите «Показать на карте», затем откройте карточку и создайте демонстрационную бронь. Проверьте пустую выдачу и возврат к каталогу.
